This project is focused on learning and understanding the active directory client and how it interacts with computer on the server.

 Build a small-business windows domain using Oracle VirtualBox and Windows Server.

 Objectives:
 * Deploy a windows server domain controller
 * Configure Active Directory Domain Services
 * Join Multiple Windows client VM's to the server
 * Manage the users, groups, and the units organization
 * Configure group policy, as well as test it
 * Practice Windows domain administration

Lab Environment:
* Hypervisor: Oracle Virtualbox
* Domain: ad.lab.test
* NetBIOS Domain: LAB
* Domain Controller: SERVER01
* Client Machines: Client01, Client02, Client03
* Virtual Network: LAB-NET
* Planned Subnet: 192.168.10.0/24
